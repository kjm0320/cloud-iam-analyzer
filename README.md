\# Cloud IAM Analyzer



AWS IAM 정책과 계정 설정의 보안 위험을 분석하는 Python 프로젝트입니다.



\## 개발 목표



\- 과도한 관리자 권한과 광범위한 권한 탐지

\- MFA 미설정 및 오래되거나 미사용인 Access Key 점검

\- 리소스의 공개 접근 가능성 점검

\- 권한 상승 후보 경로 분석 및 관계 시각화

\- 탐지 근거와 개선 방안을 포함한 JSON·HTML 보고서 생성



\## 개발 방식



1\. 가상의 IAM 정책과 계정 데이터로 오프라인 분석 기능 개발

2\. 자동 테스트로 탐지 결과 검증

3\. 비용이 발생하지 않는 범위를 확인한 뒤 AWS 읽기 전용 연동 추가



오프라인 실행에는 AWS 계정이나 인증 정보가 필요하지 않습니다.



\## 분석 한계



정적 분석 결과는 보안 검토가 필요한 후보를 나타냅니다.

실제 접근 가능 여부는 정책 조건, 명시적 거부 및 추가 통제에 따라 달라집니다.

입력 데이터가 부족한 항목은 판단 불가로 구분하는 것을 목표로 합니다.



\## 데이터 관리



공개 저장소에는 가상의 샘플 데이터만 포함합니다.

실제 계정 데이터, 인증 정보 및 비공개 분석 결과는 커밋하지 않습니다.



\## 진행 상태



개발 환경 및 저장소 초기 설정 중입니다.

위 기능은 구현 예정입니다.
